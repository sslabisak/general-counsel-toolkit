# Phased Litigation Budget

A dispute is funded one phase at a time. Each phase has a scope, an estimate, and a decision point. No phase starts without approval, and the estimate for the next phase is updated at the end of the current one.

The spreadsheet version is [03-phased-litigation-budget.csv](03-phased-litigation-budget.csv).

## Rules

1. **Estimate as a range**, and say what would push it to the high end.
2. **Report variance at 75 percent** of a phase estimate, before it is exceeded.
3. **Re-run the dispute assessment** at every decision point. If the expected result no longer justifies the next phase, say so.
4. **Track actuals by phase** so the next matter's estimate is better than this one's.
5. **Settlement value moves with the budget.** The cost of the next phase is part of what a settlement is worth today.
