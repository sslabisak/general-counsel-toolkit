# Public Claims File

Every factual claim a company makes about itself in public should have a line in this file. It takes minutes to maintain and answers the first question a regulator, a platform, a customer's security team, or an opposing lawyer will ask: what is your support for that?

The spreadsheet version is [07-public-claims-file.csv](07-public-claims-file.csv).

## What goes in

- Numbers: users, customers, growth, savings, performance, uptime
- Security and compliance statements: certifications, audits, encryption, testing
- Comparisons with competitors and "best" or "only" claims
- Customer logos, testimonials, reviews, and case studies
- Statements about what the product does not do: "we never sell," "we do not train on your data"
- Results and guarantees

## The file

| Claim (exact words) | Where it appears | Type | Support | Date of support | Owner | Status | Next review |
|---|---|---|---|---|---|---|---|
| | | Number / Security / Comparison / Testimonial / Negative / Result | Query, report, contract, or signed release, with location | | | Supported / Needs qualifier / Remove | |

## Rules

1. **Support comes first.** The evidence exists before the claim is published, not after it is challenged.
2. **Say what the number counts.** A profile is not a user, a signup is not a customer, and a pilot is not a deployment.
3. **Absolutes need absolute support.** "Never," "always," "all," and "guaranteed" are promises. Use "designed to" when describing a control.
4. **Present tense for what exists, future tense for the roadmap.** "In preparation" belongs under a roadmap heading.
5. **Testimonials:** a signed release, the person's actual experience, and a disclosure next to the quote if the person is an investor, employee, advisor, or was compensated.
6. **Comparisons:** dated, with the basis stated, and re-checked each quarter.
7. **Typical results:** if a result is not typical, say what customers can generally expect, next to the claim.
8. **One review, every quarter.** Anything unsupported is fixed or removed that day.

## Triage when a claim is challenged

| Tier | Meaning | Action |
|---|---|---|
| Fix now | Cannot be supported as written | Correct or remove today, whoever is asking |
| Defensible | Supported, and the support is on file | Hold; produce the support if required |
| Decline | The challenge misreads the claim or seeks confidential material | Respond in writing and keep the response |
